# AI Museum

Приложение для проведения виртуальных экскурсий по музею с использованием искусственного интеллекта и Telegram-бота.

## Описание

AI Museum - это интеллектуальная система, которая позволяет пользователям проходить виртуальные экскурсии по музею через Telegram-бот. Приложение использует агентов на основе LangGraph для предоставления персонализированных и интерактивных экскурсий, включая голосовое взаимодействие и обработку естественного языка.

## Требования

- Python >= 3.12
- PostgreSQL
- Docker и Docker Compose (опционально)

## Конфигурация

Создайте файл `.env` в корневой директории проекта с переменными повторяющими `.env.example`

## Запуск

### Локальный запуск

```bash
uv run -m ai_museum
```
Для локального запуска необходима внешняя PostgreSQL база данных

### Запуск с использованием Docker

```bash
docker-compose up
```

## Разработка

### Использование Nix

Проект включает конфигурацию Nix для воспроизводимой среды разработки:

```bash
nix flake show
nix develop
```
